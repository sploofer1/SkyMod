# SkyMod — Roadmap

Что делается, что планируется и что отложено. Обновляется по ходу разработки.

**Легенда:**
- 🔥 **P0** — критично, в работе сейчас или в ближайшее время.
- ⚡ **P1** — планируется, есть конкретный план.
- 💡 **P2** — идея, требует обсуждения.
- 🧊 **Icebox** — не сейчас. Хорошая идея, но не в приоритете.

## 🔥 В работе / следующее

### Рефакторинг конструктора (глобальный)

Самый крупный модуль расширения, самый запутанный. Делится на четыре части.

- [ ] **A. Пресеты**
  - [ ] Убрать `prompt()` и `confirm()` — нормальный UI: инлайн-инпут имени, инлайн-переименование, кнопка удаления с подтверждением повторным кликом.
  - [ ] Показывать активный пресет: какой именно сейчас загружен.
  - [ ] Dirty-индикатор: показать, что текущее состояние отличается от активного пресета.
  - [ ] Кнопка «↻ Обновить пресет» рядом с активным.
  - [ ] Поиск при большом количестве пресетов.
  - [ ] Всё то же самое для пресетов режима «Сайт».

- [ ] **B. Предпросмотр попапа**
  - [ ] Надёжная синхронизация размера (`compact` / `large` / `xl`) — сейчас через localStorage + попытку прописать `data-size` в contentDocument, хрупко.
  - [ ] Мгновенное обновление при изменениях (debounce ~300 мс).
  - [ ] Корректное поведение при переключении «Попап» / «Сайт».
  - [ ] Не «залипает» на старой версии кода из песочницы.
  - [ ] Не отображается пустым / чёрным / с обрезанным краем при разных ширинах окна.

- [ ] **C. Общий UX**
  - [ ] Переключатель режимов — сделать заметнее, как табы в самом попапе.
  - [ ] Статус-бар: короткие и однозначные тексты.
  - [ ] Убрать кнопку «Применить» там, где работает автосохранение по debounce; оставить Ctrl/Cmd+Enter.
  - [ ] Индикатор автосохранения: «Печатаю…» → «Сохраняю…» → «Сохранено ✓», без мигания.
  - [ ] Отладчик и консоль: не плодить дубликаты, кнопка «Скопировать ошибку», автоскролл.
  - [ ] Вкладки редактора: группировать по типу, показывать счётчик строк.
  - [ ] Хоткеи: `Ctrl/Cmd+S` — сохранить и применить, `Ctrl/Cmd+Enter` — то же в редакторе, `Esc` — снять фокус.
  - [ ] Обновить шаги обучения (`builder-tour.js`) под новый UX.

- [ ] **D. Мелкие баги**
  - [ ] Переключение режимов «Попап»/«Сайт» не всегда перерисовывает статус-бар.
  - [ ] Гонки в `partPreviewRestartSandbox` / `partPreviewMountFrame` — предпросмотр частей иногда не запускается с первого раза.
  - [ ] Проверить поведение селектов «Слой» и «Область» при переключении режимов (не подтверждено, требует сценария воспроизведения).

- [ ] **D5. Прогресс при загрузке файлов** _(отдельная итерация после A–D)_
  - [ ] Правки только в `popup.js` (плюс минимально `popup.css`).
  - [ ] Статус: «Обрабатываю…» → «Сохраняю…» → «Готово ✓» / «Ошибка: …».
  - [ ] Для больших файлов (>1 МБ) — реальный прогресс или честный спиннер.
  - [ ] Проверить, что попап в режиме `?builderPreview=1` не ломается.
  - [ ] Не трогать `content.js` и `background.js` ради этого.

## ⚡ Планируется

### Кросс-песочное взаимодействие (api.bus)

Сейчас две песочницы (`sandbox.html` и `behavior-sandbox.html`) полностью изолированы друг от друга. Хочется, чтобы код фона и код поведения карточек могли обмениваться событиями.

- [ ] Дизайн API: `api.bus.publish(name, data)` и `api.bus.subscribe(name, callback)` в обеих песочницах.
- [ ] `content.js` — реле-шина между песочницами.
- [ ] Системные события (публикует сам `content.js`):
      `skymod:card:hover`, `skymod:card:leave`, `skymod:card:click`,
      `skymod:lesson:started`, `skymod:lesson:ended`,
      `skymod:schedule:phase`, `skymod:schedule:updated`.
- [ ] Валидация имён (`[a-z0-9:_-]`, до 60 символов) и размера `data` (до 8 КБ).
- [ ] Rate-limit: не чаще 5 событий в секунду на один тип, дедупликация по содержимому.
- [ ] Работает и в предпросмотре конструктора.

### Больше частей интерфейса в реестре

Сейчас в `parts.js` — четыре части. Хочется покрыть больше элементов.

- [ ] Шапка страницы (навигация по неделям).
- [ ] Заголовки дней недели.
- [ ] Полоса обеда.
- [ ] Линии часов.
- [ ] Карточка на странице списка заданий (test-preparation).
- [ ] Кнопка «Следующее задание» на странице задачи.

### Мелкие улучшения

- [ ] Диагностика: индикатор «сколько места занимает» в каждом хранилище.
- [ ] Экспорт/импорт темы одним файлом без остальных настроек.
- [ ] Кнопка «Скопировать диагностический снимок в буфер» (сейчас только скачивание файла).
- [ ] В конструкторе: «Применить ко всем открытым вкладкам сайта» (сейчас применится само, но явная кнопка — понятнее).

## 🧊 Icebox

Не сейчас. Может быть, никогда.

- Синхронизация настроек между устройствами (потребует сервер или Chrome Sync API с ограничениями).
- Мобильная версия (у Chrome для Android нет поддержки extensions).
- Firefox / Safari порт (нужна переработка под Manifest V2/V3 и WebExtension API).
- Локализация на английский (пока все строки на русском, пользователи — русскоязычные).
- Публикация в Chrome Web Store (нужна верификация, приватность-политика, поддержка).
- Собственный редактор кода внутри конструктора (CodeMirror и т.п.) — противоречит принципу «без зависимостей».

## ✅ Недавно сделано (для контекста)

Хронология последних версий. Подробности — в [CHANGELOG.md](CHANGELOG.md).

- **2.21.0** — Проверка новых версий через GitHub API. Раз в сутки расширение запрашивает последний релиз, показывает ↑ на иконке и полоску в попапе, если вышла версия новее установленной. Опция в настройках (по умолчанию включена).
- **2.20.0** — Фон сайта получает координаты карточек занятий и своих блоков через `window.SKYMOD_CARD` и событие `skymod-card-rect`. Работает только при включённом фоне сайта, не требует «Взаимодействие с курсором».
- **2.19.3** — Единое правило «часть владеет настройками». Замки в попапе обновляются сразу, когда конструктор включает/выключает часть. Конструктор не затирает чужие правки частей.
- **2.19.2** — Исправлена работа части «Карточка занятия»: настройки попапа больше не перебивают CSS части. Парные правила для `.subject` и `.time`. Обновлены промпты и реестр частей.
- **2.19.1** — Адаптация под обновление сайта 08.10.2026: новая разметка карточки, полоска «сейчас» — маркер `.now-marker`, а не свечение. Убран классический вид расписания.
- **2.18.0** — Живой предпросмотр частей интерфейса в конструкторе.
- **2.17.0** — Поведение карточек: свои HTML и JS у частей «Карточка занятия» и «Свой блок».
- **2.16.0** — Галочка «Применять CSS карточки к своим блокам расписания».
- **2.15.0** — Модуль диагностики: снимок страницы со всеми запросами, событиями и таймерами.
- **2.14.0** — Свои блоки в расписании.
- **2.13.0** — Убрана группа «Фон урока» и «Акцентный цвет» (не работали стабильно). Размытие за окном занятия.
