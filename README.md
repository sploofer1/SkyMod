# SkyMod

**Кастомизация интерфейса [avatar.skyeng.ru](https://avatar.skyeng.ru) — цвета, шрифты, фон, расписание, свой canvas-код прямо на странице сайта.**

Расширение для Chrome (Manifest V3). Без сборки, без зависимостей — ванильный JS, работает как есть из папки.

## Что это

SkyMod — неофициальное расширение, которое меняет внешний вид личного кабинета Skyeng / Skypro. Всё делается локально, в вашем браузере: никакие данные никуда не отправляются, кроме собственного бота Telegram, если вы его подключите для напоминаний.

Расширение не заменяет функции сайта — оно **дополняет** их. Все настройки живут в `chrome.storage.local`, применяются на лету и не требуют перезагрузки страницы.

## Возможности

### 🎨 Вид
- **Фон страницы** — сплошной цвет, градиент, анимированный RGB-перелив, свой CSS или картинка/gif (ссылка или файл).
- **Шрифт** — готовые пресеты, ссылка на Google Fonts или свой файл (библиотека шрифтов хранит все загруженные разом).
- **Карточки занятий** — цвет, прозрачность, читаемость на цветном фоне, свой цвет для каждого предмета.

### 📅 Расписание
- **Свои блоки** — добавьте на сетку своё событие (репетитор, секция, работа) с цветом, временем и повтором.
- **Цвета предметов** — автоматический подбор или ручной выбор для каждого предмета.
- **Свечение под текущий урок** — фон подсвечивается цветом идущего занятия.
- **Полоска «сейчас»** — тонкая настройка цвета и вида маркера текущего времени.
- **Окно занятия** — размытие и затемнение фона, свой цвет панели.

### ⚡ Удобство
- **Внешние ссылки в новой вкладке** — сайт не закрывается при клике на внешний ресурс.
- **Блокировка трекеров** — Google Analytics и Tag Manager отключаются через `declarativeNetRequest`.
- **Скрытие элементов сайта** — кнопка поддержки, аватарка, заголовок, меню, значок в шапке.
- **Защита от блокировки при долгом отсутствии** — сайт не «заскучает» и не перезагрузит страницу.
- **Диагностика** — журнал запросов, событий и слушателей страницы для разбора багов (только локально).

### 📝 Задания
- **Кнопка «Следующее задание»** — переход к следующей задаче без возврата к списку. Перетаскивается, помнит позицию, есть горячая клавиша `Alt+N`.

### 💬 Telegram
- **Напоминания о занятиях** через вашего собственного бота — свой токен, свой чат, никакого общего сервера. Отдельные переключатели для занятий, контрольных и своих блоков.

### 🛠 Конструктор
Отдельная полноценная страница (не тесный попап) — с редактором кода, отладчиком, консолью, пресетами и живым предпросмотром.

- **Песочница попапа** — свой HTML/CSS/JS в окне расширения, поверх или под интерфейсом.
- **Фон сайта** — свой canvas/JS на весь экран avatar.skyeng.ru, работает, пока открыта вкладка.
- **Части интерфейса сайта** — свой CSS для отдельных элементов (например, полоски «сейчас»). В комплекте — готовый промпт для ИИ: скопировал, вставил в чат, получил рабочий CSS.
- **Поведение карточек** — HTML-шаблон и JS-логика для карточек занятий и своих блоков.
- **Глобальный CSS попапа** — переопределение любого стиля самого расширения.

### 🪟 Попап
- **Три размера** — компактный, крупный, максимальный (в пределах лимитов Chrome).
- **Свои цвета** — отдельно для «Mod» в шапке, для пульсов и для остального интерфейса.
- **Дорожки платы** на canvas с анимированными импульсами.
- **Экспорт / импорт** всех настроек одним файлом с выбором категорий при импорте.

## Установка

Расширение не опубликовано в Chrome Web Store. Устанавливается из исходников в режиме разработчика.

1. Скачайте или склонируйте репозиторий:
   ```bash
   git clone https://github.com/sploofer1/SkyMod.git
```

2. Откройте `chrome://extensions/`.
3. Включите **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное** и выберите папку с `manifest.json`.
5. Откройте avatar.skyeng.ru и кликните на иконку расширения.

> После установки расширение уже работает с разумными настройками по умолчанию: блокировка трекеров включена, защита от блокировки сайта включена, кнопка «Следующее задание» включена. Всё остальное — по желанию.

**Поддерживаемые браузеры:** Chrome 120+, Edge, Brave, Arc, любой другой на Chromium с поддержкой Manifest V3.

## Как это работает

Основная идея: сайт построен на CSS-переменных (`--ds-color-*` и `--ds-color2-color-*`). Вместо того чтобы точечно красить сотни элементов, расширение переопределяет несколько переменных в одном `<style>`-теге. Браузер сам применяет новый цвет везде, где эта переменная используется.

- **Цвета** — через `document.documentElement.style.setProperty(..., 'important')`, максимальный приоритет в CSS.
- **Фон страницы** — прямой `!important` на обёртки (`.page-scroll`, `.dashboard-shell`, `.topbar`), потому что они красят себя хардкодом, а не через переменные.
- **Пользовательский код** — в отдельных sandbox-страницах (`sandbox.html`, `behavior-sandbox.html`), у которых нет ни `chrome.*`, ни DOM попапа. Связь с ними — только через `postMessage`.
- **Расписание** — расширение читает карточки занятий прямо со страницы, запоминает их в `chrome.storage.local` и раз в 15 секунд пересчитывает «что идёт сейчас». Данные доступны и попапу, и коду фона.

В `content.js` **нет ни одного `setInterval` и ни одного `MutationObserver` для применения темы** — единственное действие при загрузке страницы это чтение настроек и сборка одного тега `<style>`.

## Разработка

Сборки нет. Совсем.

- Редактируйте файлы прямо в папке расширения.
- На `chrome://extensions/` нажмите **⟳ Обновить** на карточке SkyMod — изменения подхватятся.
- Вкладку сайта достаточно **обновить** (F5). Service worker перезапускается сам.
- Для отладки content script: F12 на странице сайта, вкладка **Sources** → **Content scripts** → SkyMod.
- Для отладки попапа: правый клик на иконке → **Просмотреть код попапа** (откроется DevTools в отдельном окне).
- Для отладки конструктора: F12 на открытой странице `builder.html`.

**Стиль кода:**

- ES2020 без транспиляции, никаких бандлеров.
- Комментарии на русском, по делу.
- `const`/`let`, `async`/`await`, шаблонные строки — везде, где уместно.
- Никаких внешних зависимостей.

## Вклад

Issues и pull request'ы приветствуются.

- **Баг?** Заведите issue с шагом воспроизведения и, если возможно, приложите диагностический снимок (Попап → Удобство → Диагностика → Скачать снимок).

- Добавлять внешние зависимости или сборку.

## Отказ от ответственности

SkyMod — **неофициальное** расширение. Не связано с Skyeng, Skypro или Sky Group, не одобрено и не поддерживается ими.

Расширение меняет только внешний вид интерфейса и не влияет на оценки, дедлайны или содержимое курсов. Все настройки хранятся локально в вашем браузере. Если вы подключаете уведомления Telegram — уведомления идут через вашего собственного бота, токен хранится локально и никогда не передаётся третьим лицам.

Если сайт обновится и что-то сломается — напишите issue, приложите диагностический снимок.
