                            Как работают вкладки HTML и JS
                            
HTML это шаблон: он вставляется в каждый элемент части как div.skymod-card-slot. Подстановки {{title}}, {{startLabel}}, {{progress}} и другие поля элемента. Скрипты, on*-обработчики и внешние ссылки из шаблона вырезаются.

                            
JS это тело функции с аргументом api. Он выполняется в изолированной песочнице: DOM сайта ему недоступен, он только читает данные карточек (api.onCards, api.onHover, api.onLeave, api.onClick) и отдаёт команды: api.card(id).addClass / removeClass / toggleClass / setVar / setData / setText. Результат на элементе: класс .skymod-is-имя, переменная var(--skymod-имя), атрибут [data-skymod-имя], текст в слоте [data-skymod-slot="имя"]. Оформляйте их во вкладке CSS.

                            
Кнопка «Скопировать промпт для ИИ: HTML и JS» даёт ИИ полное описание API и ограничений. Ошибки и api.log показываются в консоли выше.
